# 🌟 Lingo Toon — Next-Gen Interactive Learning Platform for Kids

> **Learn. Play. Explore.** An immersive, fluid, animated educational platform crafted for children aged 4–10. Built with modern React, Tailwind CSS, Framer Motion, and Web Audio API.

---

## ✨ Features Overview

### 1. 🎨 Dynamic Fluid Branding & 3D Claymorphism
- **Interactive 3D Hero Mascot**: Eye-tracking responsive character animations that follow the child's cursor and touch events.
- **Vibrant Saturated Claymorphic Cards**: Bespoke 3D vector emblems ("Aa", "123+", Flask, Globe, Speech bubbles, Storybook) with dual-layer clay light reflection and colorful ambient depth.
- **Scroll-Morphing Glass Capsule Navbar**: Seamless transition from a transparent hero state to a compact frosted glass floating capsule (`bg-white/65 backdrop-blur-xl`).

### 2. 🎮 Playable Educational Arcade Galaxy
- **Curated Game Pods**:
  - 🔤 **Alphabet Adventure**: Stepping stones phonics quest.
  - 🧩 **Word Builder**: Interactive drag/tap spelling engine with tactile slot placement and validation.
  - 🔢 **Math Match**: Fast-paced number pairing and math calculation challenges.

### 3. 🎬 Toon Cinema & Video Learning
- High-resolution animated storybooks, phonics sing-alongs, and nature documentaries.
- Clean cinema player with frosted glass duration tags, interactive ripple-pulse play buttons, and zero clutter.

### 4. 🧭 Interactive Adventure Learning Hub (`/learn`)
- **Claymorphic Subject Island Switcher**: Quick-filtering pods for English, Math, Science, World Knowledge, Vocabulary, and Reading.
- **Quest Journey Status Bar**: Live XP progress tracker (`380 / 500 XP`), Gold Rank Explorer status, and 5-Day Quest Streak counter.
- **Live Search & Difficulty Filters**: Instant search with clear controls and level pills (*All Levels*, *Beginner*, *Explorer*).

### 5. 👨‍👩‍👧 Comprehensive Parent Dashboard (`/parent`)
- **Safety PIN Access**: Protected mode for parents and educators.
- **Interactive Screen Time Controls**: Slider controls (15m to 90m), Bedtime Lock, and Ad Shield.
- **Weekly Analytics**: Detailed 7-day bar chart, subject mastery percentages, and curriculum breakdown.
- **Child Profile Switcher**: Easily manage multiple young learners (e.g. Alex, Mia).

### 6. 🔊 Tactile Sound & Animations
- Built-in Web Audio API synthesizer for satisfying pop clicks, success chimes, and celebration fanfares with zero dead buttons.
- Fully responsive across Mobile Phones (390px+), Tablets (768px+), and Ultrawide Desktops.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/rachitmalik-byte/lingotoon.git
cd lingotoon

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
```

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
